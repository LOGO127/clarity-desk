# 飞书公式居中真实验收记录

日期：2026-09-05。版本：本地 v0.3.0 开发构建，尚未发布。

## 结论

真实飞书 docx 文档中的 **formula-only Text 段落** 已通过应用按钮写入、服务端回读、内容保护、重复点击和飞书导出 PDF 排版检查。不是模拟 IPC 或本地公式预览。

**网页刷新后的视觉检查尚未完成**：独立 Edge 测试窗口停在飞书扫码登录页。PDF 排版核验不等于浏览器页面验收；本次也不证明用户从任意大模型复制进飞书的所有公式形式均受支持。

## 样例和权限

用户允许测试后，使用已有 user 身份授权新建一份仅含合成数据的测试文档。在线 auth status --verify 成功；没有修改用户工作文档、扩大分享权限或删除文档。

样例共有 14 个块：4 个仅含公式元素的 Text 段落（左、右、左、居中），以及说明文字、普通正文、含行内公式的正文、纯 LaTeX 文字和代码块。样例公式为质能关系、求和、定积分和勾股关系。测试文档保留供用户复核；其链接与块 ID 仅存于忽略提交的本地验收产物，不发布到仓库。

## 证据和复现

验收脚本：`scripts/feishu-live-acceptance.cjs`。必须同时传入 `CLARITY_ALLOW_TEST_DOCUMENT_WRITE=1` 和 `FEISHU_TEST_DOC_URL` 才允许启动真实写测试；不自动创建文档、不登录、不修改权限。首次必须实际修改至少一条公式，不能拿已经居中的文档充当首次成功证据。

本地证据均在 `output/playwright/`（不提交）：

- `feishu-acceptance-20260905.xml`：合成输入。
- `feishu-20260905-target.json`：获准创建的测试文档标识。
- `feishu-20260905-before.json`、`feishu-20260905-after.json`：原始服务端响应。
- `feishu-20260905-comparison.json`：独立 JSON 比对结果。
- `feishu-live-SUSynG/`：两次实际应用操作的结果、截图与隔离测试配置。
- `feishu-formula-acceptance-20260905.pdf`：飞书导出文件；已渲染并检查整页。

截图中的消息区域为防止意外保存 CLI 凭据而遮罩；脱敏消息保存在结果 JSON 中。浏览器 profile 不提交到仓库。
