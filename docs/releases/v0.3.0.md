## v0.3.0 · 轻量化公开测试版

适用于 Windows 10/11 x64。本版本标为 **Pre-release**，供试用与反馈；尚未完成所有飞书公式形式、网页显示和录音硬件组合验收。

### 下载与使用

- `Clarity-Desk-Setup-0.3.0-x64.exe`：安装版，可选择目录并创建快捷方式。
- `Clarity-Desk-Portable-0.3.0-x64.exe`：免安装便携版，首次启动需要释放运行库。
- `SHA256SUMS.txt`：同一 Release 的文件校验值。下载后可用 PowerShell 的 `Get-FileHash -Algorithm SHA256 -LiteralPath <文件路径>` 核对。

应用尚未代码签名，Windows SmartScreen 可能提示未知发布者。仅从本仓库下载并核对校验值；若安全软件拦截，请先确认来源，不要关闭系统防护。升级前正常结束并退出旧版，保留已有录音备份；不要让旧版和新版同时录音。

### 这次更新

- 默认直接打开紧凑的飞书公式工具，可选页面与 Markdown / KaTeX 按需加载。
- 去除重复运行依赖，语言资源仅保留中英文。本地便携包约 104 MB，旧版约 116 MB；本页附件大小为发布构建的实际值，不代表内存降幅。
- 修复录音授权等待时误切页面、重复启动触发活动录音恢复、分段写盘与失败状态问题；增加声源确认后最小化。
- 转写支持逐段断点重试；加强 IPC、外链与自动化测试隔离。

### 飞书公式的真实支持范围

居中按钮在 Clarity Desk 中，**不是飞书工具栏扩展**。需要先安装 `@larksuite/cli`、完成 `lark-cli auth login --domain docs`，并拥有文档编辑权限。建议先用非敏感的测试文档。

只修改仅含飞书公式元素的 Text 段落对齐，不重写公式。合成 docx 的真实按钮已验证：3 条公式修改成功，1 条已居中公式保持不变；独立读取确认其余内容完全不变，重复点击不再写入，飞书导出 PDF 中 4 条公式居中。

**仍待验收：飞书网页刷新视觉、用户实际粘贴样例、真实 wiki 和长文档。** 旧式 Equation(16) 块未验证支持，跳过并报告；图片、代码块、纯 LaTeX 文字和正文中的行内公式不处理。不能承诺“所有公式一键居中”。

### 测试与录音注意事项

本版本发布流程运行单元测试、TypeScript/生产构建、Windows 打包及打包后应用启动回归；源码 Playwright/Electron 回归另由主分支 CI 执行。现有 55 项单测及合成音频桌面回归通过。

未自动测试安装/卸载，未在本轮调用付费转写或验证真实双声源硬件。正式面试前须取得双方录音同意，做短录音并试听；系统声捕获整路默认输出，并非只捕获面试软件。转写需自行配置 OpenAI API Key，会上传混音并可能产生费用。
