## v0.3.1 · 转写重复请求修复

Windows 10/11 x64 公开测试版（Pre-release）。下载与发布状态以本版本的 GitHub Release 为准；本地验证结果不等于远端 CI 或发布已完成。

### 这次更新

- 修复同一录音的重复转写请求先排队、随后再次上传的问题。任务仍在运行时共享同一次处理，减少意外重复上传和费用风险。
- 多场录音的转写按钮独立保持忙碌状态；B 完成后，不会让仍在处理的 A 提前恢复可点击。
- 修正桌面启动回归的等待顺序，确认实际应用页面与主标题就绪后才开始检查，避免把启动空白页误当作应用。

保持轻量化方向：没有新依赖，没有改动公式识别与居中流程。任务去重仅在同一应用进程、同一录音的任务仍运行时有效；成功或失败后清理，允许后续主动重试，不承诺跨重启去重或永久免除重复费用。

### 下载与升级

- `Clarity-Desk-Setup-0.3.1-x64.exe`：安装版。
- `Clarity-Desk-Portable-0.3.1-x64.exe`：便携版，首次运行需释放运行库。
- `SHA256SUMS.txt`：核对同一 Release 附件的 SHA-256。

应用仍未代码签名，SmartScreen 可能提示未知发布者。仅从本仓库下载并核对校验值，不要关闭系统防护。升级前正常结束录音并退出旧版，保留录音备份。

### 验证范围与限制

2026-09-07 本地验证全部通过：60 项 Vitest 测试、4 项 Node 启动测试、TypeScript/生产构建、源码桌面回归（含合成 A/B 并行转写）、Windows 打包和打包后启动回归（`PACKAGED_SMOKE_OK`）。覆盖运行中任务去重、成功/失败后的重试和独立按钮状态。合成 UI 测试替换真实转写接口，不上传录音，也不产生 API 费用。

发布流水线会重新构建并检查打包应用，最终远端状态见 [Actions](https://github.com/LOGO127/clarity-desk/actions)。本地测试与测量详见 [本轮维护记录](https://github.com/LOGO127/clarity-desk/blob/v0.3.1/docs/MAINTENANCE-20260907.md)。

本轮不新增真实飞书写入、付费转写或真实双声源硬件测试。2026-09-05 的公式测试证据仍适用其原有范围，**飞书网页刷新视觉和用户实际粘贴样例仍未覆盖**；旧式 Equation(16)、图片、代码和正文中的行内公式不处理。正式面试前请取得对方同意，并用实际设备做短录音、试听；主动转写仍会上传混音并可能产生费用。
