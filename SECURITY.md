# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Please do not open a public issue containing an exploit, API key, Feishu token, private recording, or personal transcript. Use the repository's [private vulnerability report](https://github.com/LOGO127/clarity-desk/security/advisories/new) (enabled on 2026-09-05).

Include:

- affected Clarity Desk version;
- Windows and Electron versions;
- clear reproduction steps using non-sensitive test data;
- impact and suggested remediation, if known.

We aim to acknowledge reports within seven days. Never include real interview audio in a vulnerability report.

## Scope notes

Third-party services such as OpenAI, Feishu, Electron, and Chromium have their own disclosure processes. A vulnerability that only affects an unmodified upstream component should also be reported upstream.
